TengaSell is a full-stack auction marketplace built for Zimbabwean commerce — live auction rooms, structured best-offer negotiation, location-aware listing and pickup, and Paynow checkout, wrapped in the trust, moderation and finance controls a real marketplace needs.

What it looks like

Captured from the running application during the project's own UAT passes — desktop and mobile.

Built for the whole trade loop

Not a listings page — the settlement, dispute and governance path is part of the product.

Auctions

Live rooms & timed close

Scheduled start/end, bid increments, hammer and auto-close, anti-sniping, retraction handling and outbid notifications.

Offers

Best-offer negotiation

Counter-offer loop that converts directly into an order without waiting for an auction to end.

Selling

Location-aware listing

MapLibre pin selection with a tile-caching GIS service, pickup radius, delivery bands and fee preview.

Payments

Paynow & ledger

Paynow hand-off and callback handling, commission calculation, finance ledger and reconciliation hooks.

Trust

Moderation & compliance

Trust tickets, risk scoring, moderation queues, compliance console and staff RBAC with MFA flows.

Ops

Status, smoke & audits

Public status page, incident history, golden-endpoint smoke contract, plus SAST/DAST evidence packs.

This site is a static preview — the app needs a Node runtime

GitHub Pages serves static files only. TengaSell runs on 252 server routes with SQLite, WebSockets and microservices, so the live application is deployed to a Node host (Vercel, Render or Fly.io) from the same repository. This page exists so the product, architecture and evidence can be reviewed without a login. Full deployment notes are in README.md.
